# 45-minute demo script

0–5: problem, rubric, architecture and assumptions.
5–12: viewer query; show streaming/activity events, hybrid retrieval, citations and session context.
12–20: broad payment-outage query; show supervisor routing to research/RLM, plan, batch analysis and aggregation.
20–26: RBAC demo: viewer cannot use analysis/MCP; analyst can; confidential evidence is filtered by role.
26–31: attack demo: instruction override/exfiltration attempt is blocked; explain retrieved-content trust boundary.
31–36: LangSmith traces: graph transitions, retrieval/tool spans, latency/errors.
36–40: graceful failures: LLM/vector/tool timeout fallback and validation failure path.
40–43: Docker/tests/code readability and commit history.
43–45: trade-offs, production hardening and Q&A.
